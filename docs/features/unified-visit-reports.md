## Requested behavior

The map's circular Add restroom control shares the bottom glass bar's right edge. The main place card orders Hours, Amenities, Condition, then Passcodes. Rate and Comment offers one **Report visit details** action; the separate Add a note or comment action is removed.

One visit form contains the actual Visited time, an **Anonymous** switch immediately below it, existing optional entry/route/condition answers and an optional public comment. Anonymous defaults on. Switching it off uses the signed-in account's exact safe display name; there is no email or account-ID fallback. An account without a suitable display name stays anonymous. Named publication must match the fresh Firebase token's name claim.

Code required → Yes reveals an optional code field and, once filled, the existing separate code-visibility choice. The code defaults to Only me. Private code submission also saves the restroom. The code does not enter the public visit record, comment, Analytics or model input; reporting never counts as successful use. Changing Code required away from Yes excludes the hidden code from submission.

## Compatibility and submission

Keep the existing strict legacy visit and public-note schemas intact. New unified visits use an additive, exact-schema public record and a separate private ownership receipt. One stable draft and atomic transaction publish the visit/receipt and any optional immutable V2 code pairs/Saved state. Full paired readback must confirm the same frozen draft before success; unknown results retain its retry identity. Account/place guards discard stale responses.

Existing public notes and visits remain readable. New public comments and structured answers are one visitor entry. Free-text comments and names remain excluded from the on-device structured summary. Deleting an owned visit removes its public text and private receipt; the independently owned code keeps its separate visibility/removal controls. Account cleanup must understand the new namespace before new public writes are enabled.
